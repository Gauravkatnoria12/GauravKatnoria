Hey there! 👋 Welcome to the source code behind my personal portfolio — a space where I get to show off the stuff I've built, experiments I've run, and the kind of work I genuinely love doing.

---

## 🎨 What's This All About?

This is my corner of the internet. A hand-crafted, fully custom portfolio site built without any frameworks or templates — just raw HTML, CSS, and vanilla JavaScript (+ a sprinkle of Three.js magic ✨).

No page builders. No WordPress. Just code and creativity.

---

## 🚀 Features

- 🎲 **3D Loading Screen** — A rotating wireframe cube greets you on arrival. Because why not?
- 🌌 **Live WebGL Background** — An animated icosahedron + particle field that reacts to your mouse movement and scroll position
- ✍️ **Typewriter Effect** — Each project card has its own animated typing sequence
- 🎭 **About Section Animation** — A custom constellation + fluid tendril WebGL scene rendered inside the about image box
- 📱 **Fully Responsive** — Works on everything from a 4K monitor to your old phone
- 🍔 **Smooth Mobile Menu** — Slide-in nav with hamburger toggle
- 🎯 **Scroll-triggered Animations** — Project cards fade and slide in as you scroll using Intersection Observer
- 🌾 **Grain Overlay** — A subtle film grain texture over the whole page for that tactile feel
- 🖱️ **Custom Cursor** (desktop only) — Because details matter
- ⚡ **Zero dependencies** (almost) — Just Three.js from a CDN, everything else is vanilla

## 🛠️ Tech Stack

| What | How |

## 🏃 Running It Locally

Dead simple:

```bash

git clone https://github.com/gauravkatnoria12/portfolio.git

# Open the file
open index.html
```

Or just drag `index.html` into your browser. That's genuinely all you need. No npm install, no build step, no config files. 🙌
