Gaurav Katnoria 😊 — Portfolio Website

A modern creative developer portfolio website showcasing projects, design philosophy, and interactive web experiences. The site blends artistic design with advanced frontend technologies to create immersive digital experiences.

This project demonstrates how design, animation, and code can work together to create visually engaging websites.

The website includes interactive animations, a WebGL 3D environment, responsive layouts, and smooth user interactions.
